# 🔍 Fake News Detector

A machine learning project built in Python to detect and classify news articles as real or fake.

---

## 📂 Project Structure
* **`app.py`**: Main application file for running the model/interface.
* **`fake news detector/`**: Contains core logic, datasets, or model scripts.

---

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, Scikit-learn, Streamlit (or Flask)
* **Version Control:** Git & GitHub

---

## 🚀 How to Run
1. Clone the repository.
2. Install the required dependencies.
3. Run `app.py` to start the application.
